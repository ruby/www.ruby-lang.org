Ruby 3.3.14 has been released.

This release includes security fixes.
Please check the topic below for details.

* [Security advisories: multiple vulnerabilities in Regexp and String case conversion]({% link en/news/_posts/2026-11-18-multiple-vulnerabilities-in-regexp-and-string.md %})

Starting with this release, Ruby 3.3 also receives fixes for bugs that we judge need to be backported, not only security fixes.
Accordingly, we have renamed this phase from the security maintenance phase to the legacy maintenance phase.
The support period is unchanged for now, and official support for Ruby 3.3 is still scheduled to end at the end of March 2027.

Please see the [GitHub releases](https://github.com/ruby/ruby/releases/tag/v3_3_14) for further details.
