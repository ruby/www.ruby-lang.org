Ruby 3.3.13 has been released.

This release includes security fixes.
Please check the topics below for details.

* [Security advisories: CVE-2026-80212 and CVE-2026-80213]({% link en/news/_posts/2026-08-27-multiple-vulnerabilities-in-resolv.md %})
* [Regexp compilation fixes related to GitLab's CVE-2026-89078, CVE-2026-93577, CVE-2026-97229 and CVE-2026-110264]({% link en/news/_posts/2026-10-23-regexp-fixes-for-gitlab-cves.md %})

This release updates the default gem resolv to 0.3.2, which fixes CVE-2026-80212 and CVE-2026-80213.

Ruby 3.3 is in the security maintenance phase. As an exception, this release also includes fixes for bugs in Regexp compilation that GitLab's CVE-2026-89078, CVE-2026-93577, CVE-2026-97229 and CVE-2026-110264 rely on.

Please see the [GitHub releases](https://github.com/ruby/ruby/releases/tag/v3_3_13) for further details.
