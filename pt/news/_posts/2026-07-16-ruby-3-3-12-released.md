Ruby 3.3.12 foi lançado.

Esta versão inclui correções de segurança.
Consulte os tópicos abaixo para mais detalhes.

* [CVE-2026-41316: ERB @\_init deserialization guard bypass via def\_module / def\_method / def\_class]({% link en/news/_posts/2026-04-21-erb-cve-2026-41316.md %})

Esta versão atualiza a gem padrão erb para a versão 4.0.3.1 e a gem embutida net-imap para a versão 0.4.25. A atualização do net-imap corrige CVE-2026-42245, CVE-2026-42246, CVE-2026-42256, CVE-2026-42257, CVE-2026-42258, CVE-2026-47240, CVE-2026-47241 e CVE-2026-47242. Consulte as notas de lançamento de [net-imap v0.4.24](https://github.com/ruby/net-imap/releases/tag/v0.4.24) e [net-imap v0.4.25](https://github.com/ruby/net-imap/releases/tag/v0.4.25) para mais detalhes sobre essas correções.

Consulte os [lançamentos no GitHub](https://github.com/ruby/ruby/releases/tag/v3_3_12) para mais detalhes.
